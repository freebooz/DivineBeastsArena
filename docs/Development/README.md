## 人工审核验证

项目不再保留或运行自动化脚本、CI 工作流、自动登录、自动选角、自动匹配、自动旅行或模拟账户兜底路径。

登录、选角、创建角色、进入大厅和联机流程必须由审核人员在真实客户端界面中手工操作；服务端不可用、鉴权失败或角色选择失败必须显示真实失败结果，不得伪造成功。

构建仅用于工程编译检查，不构成业务验收。发布、性能、安全和联机结果均须由人工审核记录。
