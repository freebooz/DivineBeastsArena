# 中文编码规范

## 当前目标

本文定义项目中文编码、中文日志和中文注释规则。后续新增或修改源码、配置、脚本、文档时，必须保持 UTF-8，并避免跨平台构建和 Cook 过程中的编码风险。

## 编码规则

- `.h`、`.cpp`、`.cs`、`.ini`、`.json`、`.uplugin`、`.uproject`、`.md`、`.bat`、`.sh`、`.ps1` 文件必须使用 UTF-8。
- C++ 类名、变量名、函数名、文件名、模块名和插件名必须使用英文 ASCII。
- 文档正文、源码注释、日志正文和开发说明可以并应优先使用中文。
- 中文字符串字面量必须使用 `TEXT("中文内容")`。

## 日志规则

正式代码不得使用 `LogTemp` 作为长期日志分类。应使用已有日志分类或新增清晰分类，例如：

- `LogDBACore`
- `LogDBAFrontend`
- `LogDBAMatch`
- `LogDBACombat`
- `LogDBAUI`
- `LogDBAData`
- `LogDBANetwork`
- `LogDBAValidation`
- `LogDBAAI`
- `LogDBATelemetry`
- `LogDBAGameOps`

正确示例：

```cpp
UE_LOG(LogDBACombat, Warning, TEXT("技能释放失败：目标距离超过允许范围"));
```

错误示例：

```cpp
UE_LOG(LogTemp, Warning, TEXT("Failed"));
UE_LOG(LogDBACombat, Log, "中文日志");
```

## 注释规则

- 类职责注释、复杂函数注释、RPC 注释、GAS 流程注释、AttributeSet 属性注释、UI 数据来源注释、资源加载注释、Dedicated Server 分支注释和移动端适配注释必须使用中文。
- 注释应解释设计意图、边界和风险，不重复代码表面含义。

## 检查命令

```powershell
rg -n "LogTemp" DBA_GameClient/Source DBA_GameClient/Plugins -g "*.h" -g "*.cpp" -g "*.cs"
rg -n 'UE_LOG\([^,]+,[^,]+,\s*"' DBA_GameClient/Source DBA_GameClient/Plugins -g "*.h" -g "*.cpp"
Get-ChildItem DBA_GameClient/Source -Recurse -File | Where-Object { $_.Name -match '[^\x00-\x7F]' }
```

## 当前阶段不做

- 不为了消除日志风险而删除有价值日志。
- 不批量转换用户未确认的二进制资产。
- 不引入中文源码文件名或中文类名。
