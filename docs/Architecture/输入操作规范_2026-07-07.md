## 1. PC 操作规范（用户定稿）

| 输入 | 功能 | GAS InputID / 系统槽 | V2 战术类型（默认语义） |
|------|------|----------------------|-------------------------|
| **WASD** | 移动 | `Input.Move.*` GameplayTag | — |
| **鼠标** | 瞄准 / 朝向 | `Turn` / `LookUp` Axis | — |
| **鼠标左键** | 普攻 | `EDBAAbilityInputID::BasicAttack` | — |
| **Q** | 攻击技能 | `EDBAAbilityInputID::Skill01` | `Attack` |
| **W** | 控制 / 限制技能 | `EDBAAbilityInputID::Skill02` | `Control` |
| **E** | 位移 / 防护 / 功能技能 | `EDBAAbilityInputID::Skill03` | `Move` / `Function` / `Defense`（按 `DT_ZodiacSkillDefinitions` 行） |
| **R** | 终极技 | `EDBAAbilityInputID::Ultimate` | 生肖大招（非五维战术槽） |
| **Space** | 闪避 | `EDBACombatInputSlot` 预留；待 GAS Dodge 能力 | — |
| **Tab** | 切换锁定目标 | `EDBACombatInputSlot::LockTarget` → `ServerLockTarget` | — |

### 1.1 Skill04 说明

- `EDBAAbilityInputID::Skill04` / 技能槽 4 **保留**，V2 PC 默认**无键位**。
- 五维战术（攻击/移动/控制/功能/防护）在数据层通过 `DT_ZodiacSkillDefinitions` 配置；PC 仅暴露 Q/W/E + R 四个战斗键（加普攻/闪避/锁定）。

### 1.2 WASD 与 W 技能键冲突处理

规范同时要求 **WASD 移动** 与 **W = 控制技能**。实现策略：

| 场景 | W 键行为 |
|------|----------|
| **大厅 / 新手村**（`LobbyMap`、`MainLobby`） | W = 前进（魔兽世界式镜头） |
| **竞技场 / 练习 / 对局**（非大厅地图） | W = Skill02 控制技能；前进改用 **S 后退 + A/D 横移 + 鼠标朝向/右键** |

权威常量：`DBAInputMapping.h`；运行时分支：`ADBALobbyPlayerController::IsArenaCombatInputMode()`。

## 2. 输入路由架构

```
硬件输入（键鼠 / 触屏）
  → UDBAEnhancedInputComponent（DefaultInput.ini 配置）
  → UDBALobbyInputConfigDataAsset / UDBAArenaInputConfigDataAsset（软引用 InputAction）
  → UInputMappingContext（IMC_Lobby / IMC_Arena，键位映射）
  → ADBALobbyPlayerController 回调
       ├─ 普攻 → GAS TryActivateAbilityByInputID(BasicAttack) → 回退 ServerRequestAttack
       ├─ Q/W/E/R → CastEquippedSkillSlot(1~3,5) → MapEquippedSkillSlotToAbilityInputID
       ├─ Tab → CollectLockTargetCandidates → ServerLockTarget
       └─ Space → RequestDodge（GAS 待接入）
  → UDBAAbilitySystemComponent::TryActivateAbilityByInputID
  → ADBARpcHandler（ServerTryActivateAbility / ServerUltimateAbility / ServerLockTarget）
```

## 3. 大厅 vs 竞技场

| 维度 | 大厅（Frontend / Lobby） | 竞技场（Arena / Practice） |
|------|--------------------------|----------------------------|
| InputConfig | `DefaultLobbyInputConfig` | `DefaultArenaInputConfig`（可共用同一 DA） |
| IMC | `DefaultLobbyInputMappingContext` | `DefaultArenaInputMappingContext` |
| 左键短按 | 选择训练目标 | 普攻 |
| Space | Jump（Character::Jump） | 闪避（入口已接，GAS 未就绪） |
| W | 前进 | 控制技能 Skill02 |
| 右键 | 转角色 / 前进 | 转角色 / 前进（同 MOBA 镜头） |
| Tab | 未占用 | 循环锁定敌对目标 |

## 5. 需在编辑器手动创建的 IMC / IA 清单

路径建议：`Content/DBA/Input/`

### 5.1 InputAction（IA_*）

| 资产名 | Value Type | 说明 |
|--------|------------|------|
| `IA_MoveForward` | Axis1D | W/S（竞技场 W 不映射此 Action） |
| `IA_MoveRight` | Axis1D | A/D |
| `IA_Turn` | Axis1D | Mouse X |
| `IA_LookUp` | Axis1D | Mouse Y |
| `IA_BasicAttack` | Digital | 鼠标左键 |
| `IA_Skill01` | Digital | Q |
| `IA_Skill02` | Digital | W |
| `IA_Skill03` | Digital | E |
| `IA_Ultimate` | Digital | R |
| `IA_Dodge` | Digital | Space |
| `IA_CycleLockTarget` | Digital | Tab |
| `IA_LeftMouse` / `IA_RightMouse` | Digital | 大厅镜头（可选） |

### 5.2 InputMappingContext

| 资产名 | 用途 | Priority |
|--------|------|----------|
| `IMC_Lobby` | 大厅 / 新手村 | 0 |
| `IMC_Arena` | 对局 / 练习 | 1 |
| `IMC_Spectator` | 观战 | 100 |

### 5.3 InputConfig DataAsset

| 资产名 | 类型 | 说明 |
|--------|------|------|
| `DA_LobbyInputConfig` | `UDBALobbyInputConfigDataAsset` | 绑定上述 IA 软引用 |
| `DA_ArenaInputConfig` | `UDBAArenaInputConfigDataAsset`（同类型别名） | 可与 Lobby 共用或复制 |

创建完成后，在 **项目设置 → DBA Enhanced Input 设置** 或 `DefaultGame.ini` 的 `[/Script/DivineBeastsArena.DBAEnhancedInputDeveloperSettings]` 节填入软引用路径。
