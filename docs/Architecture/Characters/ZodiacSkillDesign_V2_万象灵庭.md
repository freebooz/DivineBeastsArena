## 一、设计依据

本版延续「万象灵庭」十二生肖神兽英雄体系。每个生肖对应一种灵脉职责、战斗本能和角色满足感：

| 生肖 | 灵脉职责 |
|------|----------|
| 子鼠 | 潜入暗道 |
| 丑牛 | 山岳镇守 |
| 寅虎 | 猎杀破甲 |
| 卯兔 | 月步闪避 |
| 辰龙 | 天象法域 |
| 巳蛇 | 毒纹封路 |
| 午马 | 奔袭驰援 |
| 未羊 | 祈愿护盾 |
| 申猴 | 戏法换位 |
| 酉鸡 | 破晓揭隐 |
| 戌狗 | 守阙护主 |
| 亥猪 | 岩甲反扑 |

**本版目标**不是做十二个职业模板，而是让每个生肖在**攻击、移动、控制、功能、防护/保命**五个维度上都拥有专属动作特征与明确反制点。

### 1.1 与 V15 / 现有数据体系的关系

| 维度 | V15 / 现有 | V2 万象灵庭 |
|------|------------|-------------|
| 技能数量 | 6 槽：被动 + 4 主动 + 大招 | **5 战术技能**：攻击/移动/控制/功能/防护 |
| 元素变化 | `DT_FixedSkillGroups` 12×5 元素组 | 五维技能为**生肖本体**；元素共鸣仍走 FixedSkillGroups |
| 命名 | 中文诗意名（钻影、飞牙…） | 中文战术名 + 英文代号（咬影/BiteShadow） |
| 角色名 | 子鼠·夜影灵牙 / 铁角 | 子鼠·影牙灵君 / 玄角（部分更名） |
| 数据表 | `DT_SkillNames`（72 行） | `DT_ZodiacSkillDefinitions`（60 行） |
| CD 模型 | 能量消耗 + 范围字段 | **CD 分层原则** + ConditionTag/CounterTag |
| 专属机制 | 被动叠层（灵鼠印、虎威…） | **五维专属属性**（啮伤、镇山、裂甲…） |

> **迁移策略**：V2 CSV 与 C++ Row 已就绪；GAS 能力、UI 槽位、FixedSkillGroups 引用将在 P1 逐步切换。V15 表保留至全链路验证完成。

## 二、CD 与平衡基准

### 2.1 CD 分层原则

| 技能类型 | CD 区间 | 设计约束 |
|----------|---------|----------|
| **攻击** | 5–8 秒 | 核心输出循环；高收益必须依赖生肖条件 |
| **移动** | 9–14 秒 | 入场/拉扯/支援/撤离；强位移须附带地形、目标或路线限制 |
| **控制** | 12–20 秒 | 软控可短；硬控/群控/打断需更长 CD 或更明显前摇 |
| **功能** | 18–34 秒 | 视野/标记/领域/分身/誓约/毒路/守护预置；影响战术层面 |
| **防护/保命** | 22–42 秒 | 越接近免死/强护盾/强脱控 CD 越长；**不得同时兼具高伤害和强控制** |

### 2.2 五维专属属性原则

每个生肖拥有五个专属属性，分别服务五类技能：

| 属性维度 | 影响范围 | 示例 |
|----------|----------|------|
| **攻击属性** | 伤害、破甲、流血、毒伤、重击、连锁 | 啮伤、角裂、裂甲、玉刃、雷裁… |
| **移动属性** | 位移距离、加速、冲锋、钻隙、换位、支援 | 钻隙、沉步、扑猎、踏月、御风… |
| **控制属性** | 减速、击退、沉默、失衡、封路、显形打断 | 绊足、顶阵、虎啸、月痕、龙压… |
| **功能属性** | 视野、标记、分身、领域、祝福、誓约、路径记录 | 嗅弱、山门、开猎、月影、天印… |
| **防护属性** | 护盾、减伤、脱控、免死、分伤、低血硬撑 | 避光、镇山、虎威、月闪、云护… |

每条属性均附带**平衡约束**（见各生肖详述），确保有明确反制点。

### 2.3 数值接口说明

- 本文档 CD 为初版建议值，默认按 **5v5 中节奏动作战斗**设计。
- 后续可通过等级、装备、天赋、PVE/PVP 模式进行 **±15% ~ ±25%** 调整。
- 文档不锁死最终伤害值，只给出可进数值表的参数接口（见各技能「数值接口」字段）。

> 以下每节包含：核心幻想、五维专属属性（含平衡约束）、5 个技能（含 CD、玩法、VFX、图标、台词、数值接口、平衡点）。

### 01. 子鼠·影牙灵君｜Shadowfang

**定位**：潜入刺客 / 情报侦察 / 残血收割  
**核心幻想**：从墙缝、草丛和阴影中钻出，咬住破绽，收割后撤离。

| 属性 | 名称 | 效果 | 平衡约束 |
|------|------|------|----------|
| 攻击 | 啮伤 | 暗袭、背袭、残血收割增伤；可附加短流血 | 只对嗅弱/残血/背身/落单目标高收益 |
| 移动 | 钻隙 | 靠近墙边/草丛/阴影/低视野区域时获得移动、入场、撤离收益 | 空旷地形收益低；被金鸣揭露后削弱 |
| 控制 | 绊足 | 咬腿、断步、短减速、削弱位移距离 | 无长时间硬控，主要服务追残和断逃 |
| 功能 | 嗅弱 | 感知低血/落单/刚交保命技能的目标，显示方向性气味轨迹 | 非全图透视，只给方向与短暂轨迹 |
| 防护 | 避光 | 未被直接看见或处于低视野时获得轻防护和撤离加速 | 被照明/真眼/晨鸣揭露后失效 |

#### 咬影（攻击，CD 6s）

- **玩法**：短刃与灵牙合击；对背身、残血或嗅弱目标造成额外伤害，并附加短流血。
- **VFX**：身体低伏前窜，鼠牙虚影咬住目标影子，袖刃划出幽蓝细线。
- **图标**：鼠牙咬住一片黑影，影子边缘有红色裂口。
- **台词**：「别回头，太晚了。」
- **数值接口**：啮伤伤害系数、流血时长、残血阈值、背袭角度。
- **平衡点**：爆发依赖条件；无法作为稳定正面输出。

#### 钻缝（移动，CD 12s）

- **玩法**：选择墙边/草丛/阴影或低视野点短距穿行；击杀或助攻后返还部分冷却。
- **VFX**：身体化成一线黑影钻入地面裂缝，出口处尘粒和鼠尾残影一闪。
- **图标**：地面裂缝中露出一只鼠眼和幽蓝光线。
- **台词**：「这条缝，够我过去。」
- **数值接口**：穿行距离、出口半径、返还比例、地形判定宽度。
- **平衡点**：必须依赖地形或低视野，不允许无条件远距位移。

#### 咬筋（控制，CD 10s）

- **玩法**：短跳咬向目标腿部，造成减速；若目标处于嗅弱状态，额外降低下一次位移距离。
- **VFX**：目标脚踝出现齿痕光环，黑色细线缠住脚步。
- **图标**：鼠牙咬住一条发光脚筋。
- **台词**：「脚步轻一点，命才能长一点。」
- **数值接口**：减速比例、持续时间、位移削弱比例。
- **平衡点**：偏软控，不能替代硬控开团。

#### 嗅踪（功能，CD 18s）

- **玩法**：短时间强化嗅弱感知，标出附近低血、落单或刚交保命技能目标的方向。
- **VFX**：影牙鼻尖亮起暗金光，空气中出现断续气味线。
- **图标**：鼠鼻、气味线和小型方向箭头组合。
- **台词**：「我闻到破绽了。」
- **数值接口**：探测半径、持续时间、目标类型优先级、刷新间隔。
- **平衡点**：只暴露方向，不直接显示精确坐标。

#### 藏尾（防护，CD 22s）

- **玩法**：收尾入影，获得极短不可选中与移速提升；结束后若仍在低视野，进入避光状态。
- **VFX**：鼠尾卷起，角色缩入一团黑影，地面只剩快速滑走的尾影。
- **图标**：卷曲鼠尾包住一颗黑色影珠。
- **台词**：「影子动了，是我。」
- **数值接口**：不可选中时长、移速提升、避光持续、受击取消规则。
- **平衡点**：时间很短，主要用于躲关键技能而不是长期无敌。

### 02. 丑牛·镇山玄角｜Blackhorn

**定位**：重装坦克 / 阵线锚点 / 正面反推  
**核心幻想**：站住山门，敌人越冲，越会被顶回去。

| 属性 | 名称 | 效果 | 平衡约束 |
|------|------|------|----------|
| 攻击 | 角裂 | 牛角、盾击和战锤造成破甲与震荡伤害 | 伤害依赖承伤、顶撞和墙体碰撞 |
| 移动 | 沉步 | 慢而稳，降低减速与击退影响，持盾前压不易被打断 | 提高稳定性，不提供高速追击 |
| 控制 | 顶阵 | 正面击退、打断突进、通道反推 | 方向性强，侧后方绕袭可规避 |
| 功能 | 山门 | 为身后队友建立安全输出线，提供阵地保护 | 必须站位正确，主动后撤会降低收益 |
| 防护 | 镇山 | 站定、正面受击、保护队友时获得高减伤和地脉护盾 | 背后攻击与被迫移动会明显削弱 |

#### 裂角（攻击，7s）｜「想过去？先撼动我。」
#### 沉步（移动，13s）｜「一步一山。」
#### 顶回（控制，15s）｜「你推不动。」
#### 立阵（功能，24s）｜「站到我身后。」
#### 镇山（防护，34s）｜「山不退，我不退。」

## 五、角色间平衡关系

### 5.1 高移动角色

影牙、玉灵、雷蹄、灵猴都属于高移动角色，但移动来源不同：

| 角色 | 移动来源 | 主要反制 |
|------|----------|----------|
| 影牙 | 低视野钻隙 | 揭隐（金鸣） |
| 玉灵 | 短步闪避 | 锁定控制 |
| 雷蹄 | 长距离奔雷 | 封路减速 |
| 灵猴 | 假身换位 | 照破假身（金鸣/范围伤害） |

### 5.2 高防护角色

| 角色 | 防护逻辑 | 主要反制 |
|------|----------|----------|
| 玄角 | 正面镇山 | 绕后拉扯 |
| 玉角 | 守愿免死 | 禁疗、骗守愿 |
| 天犬 | 指定护主 | 多点切入 |
| 玄鬃 | 低血岩甲 | 风筝、真实伤害 |

### 5.3 高控制角色

玄角、苍龙、幽鳞、金鸣、天犬、玄鬃都有明显控制能力，但类型不同：正面反推、领域压制、路径封锁、揭露沉默、拦截突进、近身震荡。**控制技能不得叠加为长时间无反制连控。**

### 5.4 高功能角色

苍龙、幽鳞、玉角、灵猴、金鸣、天犬功能性较强。功能技能必须有明显 CD、范围或前置条件，否则会造成信息/保护/空间压制过强。

## 六、落地到数值表的推荐字段

每个技能进入配置表时至少包含以下字段（已实现于 `DT_ZodiacSkillDefinitions.csv` + `FDBAZodiacSkillDefinitionRow`）：

| 字段 | 说明 |
|------|------|
| `SkillID` | 唯一 ID，如 `SKL_Shadowfang_BiteShadow` |
| `CharacterID` | 角色资产 ID，如 `CHRShadowfang` |
| `Zodiac` | 生肖枚举名（Rat/Ox/…） |
| `SkillType` | Attack / Move / Control / Function / Defense |
| `BaseCD` | 基础冷却（秒） |
| `CastTime` | 施法时间 |
| `Range` | 施法/突进距离 |
| `Radius` | 效果半径 |
| `Duration` | 持续时长 |
| `DamageCoefficient` | 伤害系数（初版 0/TBD） |
| `ShieldCoefficient` | 护盾系数 |
| `HealCoefficient` | 治疗系数 |
| `ControlDuration` | 控制时长 |
| `StackMax` | 最大叠层 |
| `ConditionTag` | 背袭、低血、孤立、龙域、毒纹、誓约、暗迹等 |
| `CounterTag` | 可净化、可打断、可揭露、可绕行、可驱散、可禁疗等 |
| `VFXAssetName` | 特效资产命名 |
| `IconAssetName` | 图标资产命名 |
| `VoiceLineID` | 语音行 ID |
| `VoiceLineText` | 技能台词（中文） |
| `NumericInterface` | 策划填表指引 |
| `BalanceNote` | 平衡备注 |
