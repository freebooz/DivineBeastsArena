## 1. P0-3 Widget LoadSynchronous 修复

### 问题
`UDBAMobaUserWidgetBase.cpp:81,123` 和 `DBAUserWidgetBase.cpp:106` 使用 `LoadSynchronous()` 同步加载 UI 按钮点击音效，阻塞 GameThread。

### 修复方案
将同步加载改为**异步预加载 + 缓存**模式：
1. 在 `NativeOnInitialized` 中通过 `StreamableManager` 异步加载音效软引用。
2. 加载完成后缓存到 `TWeakObjectPtr<USoundBase>` 字段。
3. `HandleAnyButtonClicked` 直接使用缓存的强指针，未就绪时跳过播放并输出中文警告日志（首次未就绪时）。
4. 保留 `DefaultClickSound` 软引用字段不变，便于设计师在 Blueprint 中配置。

### 涉及文件
- `DBA_GameClient/Source/GameCore/Public/GameCore/UI/DBAUserWidgetBase.h`
- `DBA_GameClient/Source/GameCore/Private/GameCore/UI/DBAUserWidgetBase.cpp`
- `DBA_GameClient/Source/GameMoba/Public/GameMoba/UI/UDBAMobaUserWidgetBase.h`
- `DBA_GameClient/Source/GameMoba/Private/GameMoba/UI/UDBAMobaUserWidgetBase.cpp`

### 验证
- 编译通过。
- Widget 构造时不阻塞 GameThread。
- 首次点击音效未就绪时输出中文日志，加载完成后正常播放。

## 2. P1-5 DBALoginFlowSubsystem 路径统一

### 问题
`DBALoginFlowSubsystem.cpp:545` 硬编码 `TEXT("/Game/Maps/Lobby/LobbyMap")`，与 `DBAConstants.h::Map_MainLobby`（`/Game/Lobby/Maps/MainLobby`）不一致。

### 修复方案
改为使用 `DBAConstants::Map_MainLobby` 常量作为默认值；配置覆盖逻辑保留不变。

### 涉及文件
- `DBA_GameClient/Source/GameCore/Private/GameCore/Session/DBALoginFlowSubsystem.cpp`

### 注意
`DBAConstants.h` 位于 DivineBeastsArena 模块，而 `DBALoginFlowSubsystem` 位于 GameCore 模块。GameCore 不能依赖 DivineBeastsArena。
**调整方案**：将 `Map_MainLobby` 常量迁移到 GameCore 层的 `DBAConstantsCore.h`（如不存在则创建），或在 GameCore 层定义独立的 `DBACoreMapPaths` 常量命名空间，DivineBeastsArena 层的 `DBAConstants.h::Map_MainLobby` 改为引用 GameCore 层常量。

### 验证
- 编译通过。
- 登录流程加载正确的大厅地图。

## 4. P1-3 DataTable 异步加载完成事件

### 问题
`LoadDataTable` / `RequestDataTableAsync` 模式无 `OnLoaded` 完成事件，调用方无法得知表加载完成时机。

### 修复方案
1. 抽取 `FDBAAsyncDataTableLoader` 公共工具结构体（在 GameCore 层）。
2. 提供 `Load` / `RequestAsync` / `OnLoaded` 完成事件广播。
3. 改造 `UDBAStaticDataAsset`、`UDBAZodiacHeroDataAsset`、`UDBAAbilitySetDataAsset` 使用该工具（保持向后兼容，旧接口不删除）。
4. 暴露 `OnDataTableLoaded` 多播委托。

### 涉及文件
- 新建：`DBA_GameClient/Source/GameCore/Public/GameCore/Data/DBAAsyncDataTableLoader.h`
- 修改：`DBA_GameClient/Source/DivineBeastsArena/Public/GameDBA/Data/DBAStaticDataAsset.h`
- 修改：`DBA_GameClient/Source/DivineBeastsArena/Public/GameDBA/Data/DBAZodiacHeroDataAsset.h`
- 修改：`DBA_GameClient/Source/DivineBeastsArena/Public/GameDBA/Data/DBAAbilitySetDataAsset.h`

### 风险
向后兼容需要保留旧 `LoadDataTable` 接口，可能造成代码重复。本次仅新增 `OnLoaded` 委托，不强制改造调用方。

### 验证
- 编译通过。
- 新增的 `OnDataTableLoaded` 委托可被订阅。
- 旧的 `LoadDataTable` 接口行为不变。

## 5. P1-2 IDBAValidatableInterface 普及

### 问题
仅 2 个数据资产类实现 `IDBAValidatableInterface`，其他 10+ 个类缺少运行时校验。

### 修复方案
为以下数据资产类添加 `IDBAValidatableInterface` 实现：
- `UDBAAbilitySetDataAsset`
- `UDBAZodiacHeroDataAsset`
- `UDBAStaticDataAsset`（已有 `IsDataValid`，补充 `IDBAValidatableInterface`）
- `UDBAFixedSkillGroupDataAsset`
- `UDBAAbilitySlotConfigAsset`

校验内容：
- 软引用是否有效（非空且可解析）。
- DataTable 行数是否符合预期。
- 必填字段是否非空。

### 涉及文件
- 修改：上述 5 个数据资产类的 `.h` 和 `.cpp`。

### 验证
- 编译通过。
- 校验失败时输出中文错误日志。
