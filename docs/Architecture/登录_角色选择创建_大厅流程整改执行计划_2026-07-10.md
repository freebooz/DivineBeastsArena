## 一、整改目标

本轮目标是将登录到大厅流程从“本地可走通”进一步收敛为可重复、不可重复提交、资源加载不阻塞、开发自动化不泄漏到正式包的工程实现：

1. 登录、角色选择和角色创建提交具备幂等保护。
2. 登录流程背景音乐和角色流程音频通过软引用异步加载。
3. 开发自动大厅、自动组队和自动匹配入口在 Shipping 构建中不可执行。
4. 保持 UI 状态事件驱动、外部接口异步和 C++ 逻辑约束。
5. 通过 UE 5.8 编辑器构建和后续本地流程验证。

## 三、源码变更

### 3.1 角色选择提交保护

文件：

- `DBA_GameClient/Source/DivineBeastsArena/Public/GameDBA/UI/Lobby/Login/UDBACharacterSelectFlowWidgetBase.h`
- `DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/UI/Lobby/Login/UDBACharacterSelectFlowWidgetBase.cpp`

变更内容：

- 新增 `bIsSubmittingSelection`。
- 确认提交开始后禁用“进入大厅”按钮。
- 重复调用 `ConfirmSelectedCharacter` 时记录中文日志并直接返回。
- 登录流程错误时恢复提交状态和按钮可用性。
- Widget 重新构造时重置提交状态。

### 3.2 背景音乐异步加载

文件：

- `DBA_GameClient/Source/DivineBeastsArena/Public/GameDBA/UI/DBAGameUIManager.h`
- `DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/UI/DBAGameUIManager.cpp`
- `DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/UI/Lobby/Login/UDBACharacterSelectFlowWidgetBase.cpp`
- `DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/UI/Lobby/Login/UDBACharacterCreateFlowWidgetBase.cpp`

变更内容：

- 登录、角色选择和角色创建音乐继续由 `UDBAUIDeveloperSettings` 提供软引用。
- UI 管理器使用 `RequestAsyncLoad`，不再在状态事件回调中同步加载音乐。
- 异步加载期间保存目标软路径，状态快速切换时丢弃过期回调。
- 角色选择/创建 Widget 的按钮音效和流程音效使用项目现有异步资源加载工具。
- 音乐资源为空、路径无效、异步句柄创建失败和加载结果为空时均输出中文诊断。

### 3.3 开发自动化隔离

文件：

- `DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/GameInstance/DBAGameInstance.cpp`

变更内容：

- Shipping 构建不执行 `DBAAutoLobbyFlow`。
- Shipping 构建不执行 `DBAAutoPartyLeader`。
- Shipping 构建不执行 `DBAAutoMatchFlow`。
- 正常登录、角色选择和进入大厅链路不增加自动匹配逻辑。

## 六、验收标准

- 登录按钮点击后只能产生一个有效登录请求。
- 角色选择确认连续点击只产生一次选择请求和一次大厅进入流程。
- 角色创建连续点击只产生一次创建请求。
- UI 状态切换不依赖同步音频加载。
- 过期音频回调不会恢复已离开页面的音乐。
- Shipping 构建不执行开发自动大厅、自动组队和自动匹配命令行流程。
- 真实后端和打包服务器的待验收项必须有独立日志证据，不能用模拟回退流程替代。
