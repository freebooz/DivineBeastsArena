## UE 源码领域目录

Arena 项目层允许的一级领域：Animation、Character、Combat、Core、Data、Framework、Frontend、GameInstance、GAS、Input、Navigation、Player、RPC、Services、Spectator、UI、Utilities、VFX。

新增一级领域前必须证明现有目录无法表达其所有权。Common 只允许存放同一模块、同一功能域的共享表现组件，不允许作为跨层垃圾目录。

## UE 资产目录

新建项目资产统一进入 Content/DBA：

| 目录 | 职责 |
| --- | --- |
| Content/DBA/Core | 项目共享样式、通用材质和基础配置资产 |
| Content/DBA/Moba | 可复用 MOBA 资源 |
| Content/DBA/Arena | 生肖、元素、五营、地图、项目 UI、VFX 与音频 |
| Content/DBA/Data | DataTable、PrimaryDataAsset、配置与本地化数据 |
| Content/DBA/Experimental | 经过登记的实验和 MCP 生成资产 |

存量 Content 顶层目录冻结，不再新增资产。迁移必须通过 Unreal Editor/MCP 事务执行，不允许文件系统移动 .uasset 或 .umap。

## 文件命名

- C++ 类文件名与主类型一致，不在类文件名中重复模块名。
- DataAsset：DA_DBA_领域_名称。
- DataTable：DT_DBA_领域_名称；现有发布资产保留旧名，迁移时建立重定向和来源清单。
- Widget Blueprint：WBP_DBA_领域_名称。
- Actor Blueprint：BP_DBA_领域_名称。
- Material/Instance：M_DBA_名称、MI_DBA_名称。
- Niagara：NS_DBA_名称、NE_DBA_名称。
- 输入：IA_DBA_动作、IMC_DBA_场景。
- 人工审核：记录进入 `docs/Development` 或对应架构审查文档；不得新增自动化测试脚本。
- npm 包：dba-game-admin、dba-game-website、dba-game-launcher。
- Rust package：dba-game-launcher；lib 名保持 game_launcher_lib。
