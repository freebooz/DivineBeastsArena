## 2. P0 问题清单与执行计划

### P0-1：GAS 生肖大招未调用 CommitAbility（阻断性）✅

- **来源**：GAS系统审查报告 P0-2
- **文件**：`DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/GAS/Abilities/DBAZodiacUltimateAbility_Generic.cpp`
- **位置**：第 20-41 行 `ActivateAbility`
- **问题**：`ActivateAbility` 调用 `Super::ActivateAbility` 后未调用 `CommitAbility`，导致大招能量不扣减、冷却不应用、Cost GE 不生效。
- **修复方案**：在 `Super::ActivateAbility` 后调用 `CommitAbility(Handle, ActorInfo, ActivationInfo)`，失败时输出中文日志并 `EndAbility(Handle, ActorInfo, ActivationInfo, true, true)`。
- **实际执行**：将 `Super::ActivateAbility` 移到最前，在其后添加 `CommitAbility` 调用，失败时输出 `UE_LOG(LogDBACombat, Warning, ...)` 中文日志并 `EndAbility`。
- **状态**：✅ 已完成

### P0-2：GAS 共鸣 GE 硬编码 LoadObject 同步加载 + 路径拼写错误（阻断性）✅

- **来源**：GAS系统审查报告 P0-1
- **文件**：`DBA_GameClient/Source/DivineBeastsArena/Private/GameDBA/GAS/Effects/DBAGE_Fire_Resonance.cpp`（及 Water/Wood/Gold/Earth 共 5 个文件）
- **位置**：构造函数第 18 行
- **问题**：
  1. 构造函数硬编码 `LoadObject<UDataTable>` 同步加载，阻塞 GameThread。
  2. 路径 `DBAElementResonanceRowe` 拼写错误（应为 `Row`）。
  3. 中文注释全部 mojibake 乱码。
- **修复方案**：
  1. 将 DataTable 引用迁移为 `TSoftObjectPtr<UDataTable>` 静态配置入口（通过 DeveloperSettings 或类静态成员）。
  2. 修正路径拼写错误。
  3. 修复中文注释乱码。
  4. 由于 GE 构造函数在 CDO 阶段执行，采用延迟加载模式：构造函数仅记录软引用，运行时首次使用时异步加载。
- **实际执行**：由于 GE 构造函数在 CDO 阶段执行，Modifier 必须在此配置，因此保留同步加载但路径常量化到 `DBAConstants::DT_ElementResonance`（在 `DBAConstants.h` 中新增并修正拼写错误 `Rowe → Row`），修复全部中文注释 mojibake，添加 null 检查和中文错误日志（`UE_LOG(LogDBACombat, Warning, ...)`）。5 个 GE 文件结构一致，仅元素名不同。
- **状态**：✅ 已完成
